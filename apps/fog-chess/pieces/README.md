# Piece images

The *cburnett* piece set by Colin M.L. Burnett, as published in lichess's
repository ([lichess-org/lila](https://github.com/lichess-org/lila),
`public/piece/cburnett`). lichess lists it under GPLv2+; see that repository's
`COPYING.md` for the exact terms.

These copies came from battle-simulator's `games/chess/images/`, which
downloaded them with its `scrape-images.mjs`.
